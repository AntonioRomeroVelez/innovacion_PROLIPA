🎧 Voces para tus cuentos

Cómo se usa
  1. Escucha. Fíjate en el ritmo, las pausas, la pronunciación (ll, rr, ñ, j) y si suena a persona contando o a máquina.
  2. Si una voz suena robótica, toca 🤖. Con Copiar la lista de descartadas y pegándola en herramientas/voces-descartadas.json queda anotada para siempre.
  3. Si te gusta, toca Copiar y pégala dentro de voces: { … } en el texto.js de tu cuento.
  4. Ejecuta python herramientas/generar.py mi-cuento para grabar la narración.
Para cambiar cómo suena un personaje del catálogo, edita su línea en lecturas/_comun/voces.js y vuelve a ejecutar generar.py.
